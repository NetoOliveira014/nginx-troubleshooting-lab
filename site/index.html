PRINCÍPIOS

O sintoma aponta a camada

Timeout, recusa e código HTTP contam histórias diferentes.

Quando o erro muda, você avançou

Cada correção revela a próxima falha escondida.

Valide antes de aplicar

Sempre nginx -t antes de ligar ou reiniciar.

Root esconde problemas

Teste com o usuário do serviço, não com o administrador.
